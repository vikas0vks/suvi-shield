# Security policy

Please report extension security issues privately to the project owner before public disclosure. Include the affected version, browser version, reproduction steps, expected security boundary and demonstrated impact. Do not include unrelated browsing data or credentials.

The project treats remote-code execution, extension-origin XSS, privilege escalation through message handling, silent protection bypass, malicious filter-data execution and unauthorized browsing-data disclosure as security issues. Filter coverage gaps and ordinary site breakage are usually correctness issues unless they cross a security boundary.
